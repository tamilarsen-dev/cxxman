std::sort  <algorithm>
                  C++98 · ⚑ constexpr C++20 · parallel C++17
Sort a range in ascending order. Not stable.

  sort(first, last)
  sort(first, last, comp)
      comp(a, b) -> bool: true if a goes before b
  ranges::sort(r, comp = {}, proj = {})
      ⚑ C++20 · returns iterator to end of r

  // ascending
  std::sort(v.begin(), v.end());
  // descending
  std::sort(v.begin(), v.end(), std::greater<>{});
  // by member  ⚑ C++20
  std::ranges::sort(people, {}, &Person::age);

  ! needs random-access iterators: for std::list use
    l.sort()
  ✗ comp must be a strict weak ordering: use <, never <=
  ! equal elements may change order: use stable_sort to keep
    it

O(n log n) comparisons
