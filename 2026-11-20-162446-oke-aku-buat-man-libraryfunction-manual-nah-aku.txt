  Isinya adalah spesifikasi untuk Codex.

  1. Halaman default berupa "quick card" yang muat satu layar (sekitar 30 baris
  untuk fungsi, sekitar 40 untuk class):

  std::sort — sorts a range into ascending order
  #include <algorithm>

  SYNOPSIS
    (1) template< class RandomIt >
        void sort( RandomIt first, RandomIt last );     (constexpr since C++20)
    (2) ... Compare comp );
    +2 overloads with ExecutionPolicy (C++17), std::ranges::sort (C++20) — 
  --full

  PARAMETERS   first, last   the range of elements to sort
  RETURNS      (none)
  COMPLEXITY   O(N·log(N)) comparisons ...
  WATCH OUT    • The order of equal elements is not guaranteed to be preserved.
  EXAMPLE      (hanya kalau contohnya ≤ 15 baris, kalau tidak: cxxman sort 
  --example)
  SEE ALSO     stable_sort, partial_sort, ranges::sort
  More: cxxman sort --full · <url cppreference>

  - Return type langsung terlihat karena deklarasinya ditampilkan utuh.
  - Supaya pendek, isi dipilih dan sebagian disembunyikan. Kalimat sumber tidak
    pernah diringkas atau ditulis ulang, jadi akurasi tetap aman.
  - Setiap kali ada isi yang disembunyikan, muncul satu baris petunjuk ke
    --full.

  2. UX untuk mencari "aku mau pakai apa":
  - cxxman header algorithm menampilkan semua fungsi di header itu,
    masing-masing dengan penjelasan satu baris.
  - cxxman search remove duplicates akan menampilkan unique di urutan atas,
    lengkap dengan penjelasan singkatnya.
  - Alias didukung, misalnya any_of dan none_of membuka halaman yang sama dengan
    all_of.
  - Kalau topik tidak ketemu, cxxman menyarankan sampai 3 nama yang mirip.

  3. Cakupan seluruh library. Saya mengartikan "semua STL" sebagai seluruh C++
  standard library di cppreference /cpp/, termasuk <cstring>, <cmath>, dan
  sejenisnya. Halaman bahasa inti, keyword, dan experimental/TS tidak masuk.
  Indeks simbolnya punya sekitar 1.200 link, jadi kalau halaman member ikut
  dihitung totalnya sekitar beberapa ribu halaman. Katalog tidak lagi ditulis
  tangan, tetapi dibuat oleh tool tools/build_catalog.py.

  4. Milestone M1 sampai M8 menggantikan urutan di file audit sebelumnya. M1
  tetap dimulai dari fixture HTML cppreference asli.

  Yang ikut diperbarui: AGENTS.md (poin 8 sekarang menunjuk ke spec dan memuat
  aturan quick card), docs/roadmap.md, docs/continuation.md, dan file audit
  diberi catatan bahwa urutan milestonenya sudah diganti.

  Satu keputusan yang perlu dari kamu: mendownload ribuan halaman dari setiap
  komputer pengguna itu lambat dan membebani cppreference. Saran saya, database
  dibangun sekali di CI lalu dirilis sebagai satu file, sehingga cxxman update
  cukup mengunduh file itu. Masalahnya, konten cppreference berlisensi
